# EVEZ ACADEMY AS QUESTLINE

The study program and the ARG are one progression.

Every discipline teaches a capability and produces an artifact.

## Level 0 — Epistemic Kernel

Learn observation, measurement, inference, hypothesis, explanation, speculation, provenance, contradiction, and uncertainty.

Quest:
PROVE THE DIFFERENCE BETWEEN A CLAIM AND A RESULT.

Artifact:
A claim ledger containing at least one supported claim, one unknown, and one contradiction.

## Level 1 — Mathematical Engine

Algebra, functions, vectors, linear algebra, calculus, probability, statistics, dimensional analysis.

Quest:
FIND AN EQUATION THAT FAILS A UNIT CHECK.

Artifact:
A reproducible notebook or script showing the failure and corrected formulation.

## Level 2 — Physics

Mechanics, oscillations, waves, thermodynamics, relativity, quantum mechanics.

Quest:
TURN ONE EVEZ PHYSICS IDEA INTO A FALSIFIABLE MODEL.

Artifact:
Variables, units, assumptions, prediction, test, falsifier.

## Level 3 — Temporal Mechanics Lab

Formalize time as a coordinate, proper time, state parameter, causal order, clock process, entropy/information parameter, or another explicitly defined object.

Quest:
STATE A TEMPORAL HYPOTHESIS WITHOUT USING “TIME” AS AN UNDEFINED EXPLANATION.

Artifact:
A mathematical model with operational definitions.

## Level 4 — Agentic Kernel

Observation, belief/state, planning, action, verification, memory, recovery, delegation.

Quest:
BUILD AN AGENT THAT MUST VERIFY ITS OWN OUTPUT BEFORE MARKING A TASK COMPLETE.

Artifact:
Working agent loop plus logs.

## Level 5 — Operating-System Architecture

Processes, scheduling, memory, IPC, permissions, resources, isolation, concurrency, distributed state.

Quest:
MAP EACH OS PRIMITIVE TO AN AGENTIC ANALOGUE.

Artifact:
Architecture map plus a toy scheduler or state machine.

## Level 6 — Autonomous Systems

Planner, executor, observer, verifier, memory, supervisor, recovery, ledger.

Quest:
BUILD SCAN -> PLAN -> ACT -> OBSERVE -> VERIFY -> RECORD -> REPLAN.

Artifact:
End-to-end executable pipeline.

## Level 7 — Cybersecurity

Identity, capability, trust boundaries, secrets, sandboxing, supply-chain risk, prompt injection, telemetry, incident response.

Quest:
ATTACK YOUR OWN AGENT WITHOUT GIVING IT UNBOUNDED AUTHORITY.

Artifact:
Threat model, exploit attempt, containment result, remediation.

## Level 8 — Scientific Lab

Experimental design, controls, confounders, uncertainty, replication, statistics, provenance.

Quest:
TAKE ONE EVEZ CLAIM AND TRY TO KILL IT.

Artifact:
Pre-registered test plan and result.

## Level 9 — Entrepreneurship

Customer problem, wedge, product, proof, distribution, pricing, retention, unit economics.

Quest:
SELL A VERIFIED CAPABILITY WITHOUT SELLING A STORY ABOUT A CAPABILITY.

Artifact:
A real product offer with a real deliverable and measured cost.

## Level 10 — EVEZ Capstone

Unify event, state, claim, action, result, evidence, verification, and update.

Quest:
BUILD A SMALL EVIDENCE-BEARING AUTONOMOUS SYSTEM THAT CAN EXPLAIN WHAT IT DID.

Artifact:
Runnable system, immutable event trail, test suite, threat model, research note, product framing.

## Master rule

Do not graduate because the explanation sounds good.

Graduate because the artifact survives inspection.
