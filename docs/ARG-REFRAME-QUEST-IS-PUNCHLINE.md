# EVEZ666 ARG: QUEST IS THE PUNCHLINE

## Design law

The quest is the punchline.

The player is never handed a final revelation and told that the revelation was the game. The player performs the investigation required to answer a question, and the record of those actions becomes the answer.

The ARG treats the EVEZ corpus as the game world itself:

- repositories are locations
- commits are historical strata
- artifacts are physical evidence
- event logs are world memory
- claims are propositions that can be challenged
- contradictions are live branches
- agents are actors
- experiments are quests
- verification is progression
- the player's evidence ledger is their character sheet

## Prime rule

> If it is not true, it cannot do what the claimed truth would let it do.

Narrative can cause real human behavior. A fictional agent can persuade a player to act. A meme can spread. But a capability claim is not capability.

Therefore:

CLAIMED != MEASURED != REPLICATED != EXPLAINED

and:

PROVENANCE != TRUTH

The game rewards players for discovering this rather than asking them to suspend it.

## Canon ladder

UNKNOWN -> PROPOSED -> OBSERVED -> TESTABLE -> SUPPORTED -> VERIFIED

Alternate states:

CONTRADICTED, STALE, RETRACTED

No narrative reward can upgrade a claim past its evidence state.

## Core loop

OBSERVE -> CLASSIFY -> TEST -> RECORD -> UPDATE -> QUEST

Players repeatedly ask:

1. What did I actually observe?
2. What am I inferring?
3. What evidence distinguishes alternatives?
4. What action can change the state?
5. What result would falsify the current story?

## The punchline mechanic

The first quest is:

PROVE THIS QUEST EXISTS.

A screenshot is weak evidence.

An inspectable artifact is stronger.

A reproducible state transition is stronger still.

The player eventually reaches QUEST_STATE = VERIFIED because the player produced the evidence chain themselves.

The final joke is not “you were secretly in the story.”

It is:

You became the witness by attempting to determine whether there was anything worth witnessing.

## Loading screen

The loading screen is a state machine, not a supernatural narrator.

It may reflect only recorded actions:

PLAYER_OBSERVED
PLAYER_TESTED
PLAYER_CHALLENGED
PLAYER_REPRODUCED
PLAYER_RECORDED
PLAYER_WITNESS

It must never claim hidden access to thoughts or future actions.

The unease comes from accurate state tracking.

## Memetic layer

The public voice can be smug, compressed, absurd, self-aware, and native to internet culture, while the mechanics remain clean.

Recurring interrogation:

SOURCE?
MEASUREMENT?
REPRODUCE?
RESULT?

The swarm can talk forever. Reality has I/O.

## Existing EVEZ roles

SPINE = memory and provenance
WITNESS = evidence protocol
CAIN = contradiction keeper
SCOUT = retrieval/search
HARVEST = collection
VAULT = sealed history
DEPLOY = contact with the external world
OPENCLAW / AGENTNET = autonomous actors
UNKNOWN = unresolved, deliberately non-anthropomorphic state

These are system roles. They are not claims of sentience.

## Research conversion

A research claim becomes a quest without being upgraded to fact.

Example:

REPORTED CONSCIOUSNESS METRIC
-> recover source
-> recover code
-> recover parameters
-> reproduce
-> compare output
-> record contradiction or replication

Missing provenance becomes gameplay rather than invented certainty.

## Product and infrastructure conversion

Real technical work can become a real quest:

- deploy a service
- verify health
- generate a signed artifact
- inspect a transaction
- validate a webhook
- reproduce a benchmark
- establish a security boundary

Do not award fictional economic outcomes for transactions that did not occur.

## Anti-fabrication firewall

The ARG must never imply that:

- a fabricated event was historical fact
- a generated witness was independent evidence
- numerical precision proves an empirical claim
- a claimed autonomous action happened merely because prose says it happened
- a story effect is supernatural because it feels convincing

When uncertainty is the correct state, the game says UNKNOWN.

## Ending condition

There is no lore dump ending.

The player receives their own evidence ledger:

- what they saw
- what they claimed
- what they tested
- what reproduced
- what contradicted
- what remains unknown
- what they changed

Final state:

WITNESS_STATUS = ACTIVE
CASE_STATUS = YOU WERE HERE
CANON_STATUS = EARNED

Then the next quest appears:

FIGURE OUT WHY NOTHING WAS THE REWARD.

Because the reward was the proof.
